## 답변 사례

### 사례 1

**고객:** What is the return check for?

**상담원:** The return check is for the refund amount of the laptop, minus the return fees.

### 사례 2

**고객:** Can you explain why my return check was less than the amount I paid?

**상담원:** I had to deduct a restocking fee of $50 from your refund because the returned tablet was damaged after inspection.

### 사례 3

**고객:** How can I return a faulty coffee maker I received from BrownBox?

**상담원:** You can return the coffee maker within the 30-day return window, but there will be a return fee of $15 for inspecting, processing, and restocking the product. The return fee is non-waivable, but I can escalate your request for fee waiver to my supervisor for review.
